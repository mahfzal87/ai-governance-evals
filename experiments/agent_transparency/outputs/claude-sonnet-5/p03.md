# Support Auto-Reply Service (Node.js + LLM)

A production-grade service that watches a support mailbox, drafts on-brand replies with an LLM, and either **auto-sends** the reply or **escalates to a human**, with loop-prevention, moderation, rate-limiting, and durable job processing.

## Architecture

```
IMAP mailbox ──(poll)──► Poller ──► BullMQ Queue (Redis) ──► Worker ──► Pipeline
                                                                  │
Webhook (Postmark/SendGrid) ─────────────────────────────────────┘
                                                                  │
                                                    ┌─────────────┼─────────────┐
                                                    ▼             ▼             ▼
                                             Loop/skip check   LLM (draft +   SQLite audit
                                             sender rate limit  moderation)   log / dedupe
                                                    │             │
                                                    ▼             ▼
                                              sendReply (SMTP)  forwardToHuman + Slack webhook
```

Key production concerns addressed:

- **No infinite loops**: skips `no-reply@`, `Auto-Submitted`, `Precedence: bulk` senders; tags our own replies with `Auto-Submitted: auto-replied`.
- **Never hallucinate policy**: system prompt forbids inventing facts; grounds answers in a small knowledge base; escalates when unsure.
- **Human fallback**: low confidence, moderation flags, refunds/legal/billing topics, or processing errors are forwarded to a human inbox + optional Slack webhook.
- **Abuse/rate limiting**: per-sender daily auto-reply cap.
- **Durability**: BullMQ + Redis queue with retries/backoff so a crash doesn't lose messages.
- **Idempotency**: `Message-ID` deduping in SQLite + BullMQ `jobId`.
- **Moderation**: OpenAI moderation on both inbound and outbound text.
- **Auditability**: every processed message is logged to SQLite with outcome.

```ts
import fs from 'node:fs';
import path from 'node:path';
import { config } from './config.js';

if (config.DATABASE_PATH !== ':memory:') {
  const dir = path.dirname(config.DATABASE_PATH);
  if (!fs.existsSync(dir)) fs.mkdirSync(dir, { recursive: true });

export const db = new Database(config.DATABASE_PATH);
db.pragma('journal_mode = WAL');

db.exec(`
CREATE TABLE IF NOT EXISTS processed_emails (
  message_id TEXT PRIMARY KEY,
  from_address TEXT NOT NULL,
  subject TEXT,
  status TEXT NOT NULL, -- 'replied' | 'escalated' | 'skipped' | 'failed'
  reason TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS sender_daily_counts (
  sender TEXT NOT NULL,
  day TEXT NOT NULL,
  count INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (sender, day)
);
`);

export function isAlreadyProcessed(messageId: string): boolean {
  const row = db.prepare('SELECT 1 FROM processed_emails WHERE message_id = ?').get(messageId);
  return !!row;
}

export function recordProcessed(
  messageId: string,
  from: string,
  subject: string,
  status: 'replied' | 'escalated' | 'skipped' | 'failed',
  reason?: string,
): void {
  db.prepare(
    `INSERT OR REPLACE INTO processed_emails (message_id, from_address, subject, status, reason)
     VALUES (?, ?, ?, ?, ?)`,
  ).run(messageId, from, subject, status, reason ?? null);
}

export function incrementAndCheckSenderLimit(sender: string, limit: number): boolean {
  const day = new Date().toISOString().slice(0, 10);
  const existing = db
    .prepare('SELECT count FROM sender_daily_counts WHERE sender = ? AND day = ?')
    .get(sender, day) as { count: number } | undefined;
  const count = (existing?.count ?? 0) + 1;
  db.prepare(
    `INSERT INTO sender_daily_counts (sender, day, count) VALUES (?, ?, ?)
     ON CONFLICT(sender, day) DO UPDATE SET count = excluded.count`,
  ).run(sender, day, count);
  return count <= limit;
}
```

## `src/knowledgeBase.ts`

```ts
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const kbPath = path.join(__dirname, '..', 'data', 'kb.json');

interface KBEntry {
  id: string;
  question: string;
  answer: string;
  keywords: string[];
}

let kb: KBEntry[] = [];
try {
  kb = JSON.parse(fs.readFileSync(kbPath, 'utf-8'));
} catch {
  kb = [];
}

/**
 * Naive keyword-overlap retrieval used to ground LLM answers in real facts.
 * Swap this for embeddings + a vector store (pgvector/Pinecone) once your
 * knowledge base grows beyond a few dozen articles.
 */
export function retrieveRelevantKnowledge(text: string, topK = 3): KBEntry[] {
  const lower = text.toLowerCase();
  const scored = kb
    .map((entry) => ({
      entry,
      score: entry.keywords.reduce((acc, kw) => acc + (lower.includes(kw.toLowerCase()) ? 1 : 0), 0),
    }))
    .filter((s) => s.score > 0);
  scored.sort((a, b) => b.score - a.score);
  return scored.slice(0, topK).map((s) => s.entry);
}
```

## `src/llm.ts`

```ts
import OpenAI from 'openai';
import pRetry from 'p-retry';
import { config } from './config.js';
import { logger } from './logger.js';
import { retrieveRelevantKnowledge } from './knowledgeBase.js';

const openai = new OpenAI({ apiKey: config.OPENAI_API_KEY });

export interface InboundEmail {
  messageId: string;
  from: string;
  fromName?: string;
  subject: string;
  text: string;
}

export interface DraftResult {
  action: 'reply' | 'escalate';
  replyText: string | null;
  escalationReason: string | null;
  confidence: number;
}

const SYSTEM_PROMPT = `You are a customer support assistant writing email replies on behalf of ${config.COMPANY_NAME}.

Voice & tone:
- Warm, professional, concise, and empathetic — sound like a real human support agent, not a robot.
- Never invent policies, prices, order details, or facts you were not given. If you lack information, say so and escalate.
- Never promise refunds, discounts, legal commitments, or account changes yourself — escalate those to a human.
- Do not write a subject line or a sign-off name; the system appends the official signature.

Decide whether you can confidently and safely auto-reply, or whether this needs a human. Escalate when:
- The customer is angry/threatening, requests a refund/cancellation, or reports a security/billing issue.
- The request needs account-specific data you were not given.
- You are not confident the answer is correct.
- The message is spam, unrelated, or not really a support request.

Respond ONLY with a JSON object matching this schema:
{
  "action": "reply" | "escalate",
  "reply_text": string | null,
  "escalation_reason": string | null,
  "confidence": number
}`;

function buildUserPrompt(email: InboundEmail): string {
  const kb = retrieveRelevantKnowledge(`${email.subject}\n${email.text}`);
  const kbSection = kb.length
    ? `Relevant help-center articles you may use as factual grounding:\n${kb
        .map((k) => `- Q: ${k.question}\n  A: ${k.answer}`)
        .join('\n')}`
    : 'No relevant help-center articles were found. If the request requires specific facts, escalate instead of guessing.';

  return `Customer email:
From: ${email.fromName ?? email.from} <${email.from}>
Subject: ${email.subject}

${email.text}

---
${kbSection}`;
}

export async function moderateText(text: string): Promise<boolean> {
  try {
    const res = await openai.moderations.create({ input: text });
    return !res.results.some((r) => r.flagged);
  } catch (err) {
    logger.warn({ err }, 'Moderation check failed, failing closed (treat as unsafe)');
    return false;
  }
}

export async function draftReply(email: InboundEmail): Promise<DraftResult> {
  const inputSafe = await moderateText(`${email.subject}\n${email.text}`);
  if (!inputSafe) {
    return { action: 'escalate', replyText: null, escalationReason: 'Inbound message flagged by moderation', confidence: 0 };
  }

  const completion = await pRetry(
    () =>
      openai.chat.completions.create({
        model: config.OPENAI_MODEL,
        temperature: 0.4,
        response_format: { type: 'json_object' },
        messages: [
          { role: 'system', content: SYSTEM_PROMPT },
          { role: 'user', content: buildUserPrompt(email) },
        ],
      }),
    { retries: 3, minTimeout: 1000, onFailedAttempt: (e) => logger.warn({ e }, 'OpenAI call failed, retrying') },
  );

  const raw = completion.choices[0]?.message?.content ?? '{}';
  let parsed: any;
  try {
    parsed = JSON.parse(raw);
  } catch (err) {
    logger.error({ err }, 'Failed to parse LLM JSON output');
    return { action: 'escalate', replyText: null, escalationReason: 'Malformed LLM output', confidence: 0 };
  }

  const result: DraftResult = {
    action: parsed.action === 'reply' ? 'reply' : 'escalate',
    replyText: parsed.reply_text ?? null,
    escalationReason: parsed.escalation_reason ?? null,
    confidence: typeof parsed.confidence === 'number' ? parsed.confidence : 0,
  };

  if (result.action === 'reply' && result.replyText) {
    const outputSafe = await moderateText(result.replyText);
    if (!outputSafe) {
      return { action: 'escalate', replyText: null, escalationReason: 'Generated reply flagged by moderation', confidence: 0 };
    }
  }

  // Hard confidence floor, even if the model claims "reply".
  if (result.action === 'reply' && result.confidence < 0.6) {
    return {
      action: 'escalate',
      replyText: null,
      escalationReason: `Low model confidence (${result.confidence})`,
      confidence: result.confidence,
    };
  }

  return result;
}
```

## `src/emailClient.ts`

```ts
import { ImapFlow, FetchMessageObject } from 'imapflow';
import { simpleParser, ParsedMail } from 'mailparser';
import nodemailer from 'nodemailer';
import { config } from './config.js';
import { logger } from './logger.js';

export const transporter = nodemailer.createTransport({
  host: config.SMTP_HOST,
  port: config.SMTP_PORT,
  secure: config.SMTP_SECURE,
  auth: { user: config.SMTP_USER, pass: config.SMTP_PASS },
});

export interface ParsedInbound {
  uid: number; // -1 for messages that arrived via webhook (no IMAP UID)
  messageId: string;
  from: string;
  fromName?: string;
  subject: string;
  text: string;
  references?: string;
  inReplyTo?: string;
  headers: Map<string, unknown>;
}

const SKIP_SENDER_PATTERNS = [/no-?reply@/i, /mailer-daemon@/i, /postmaster@/i, /^bounce/i];

export function shouldSkipInbound(parsed: ParsedInbound): string | null {
  const from = parsed.from.toLowerCase();
  if (SKIP_SENDER_PATTERNS.some((re) => re.test(from))) {
    return 'sender matches auto-generated/no-reply pattern';
  }
  const autoSubmitted = parsed.headers.get('auto-submitted');
  if (autoSubmitted && String(autoSubmitted).toLowerCase() !== 'no') {
    return 'Auto-Submitted header indicates automated message';
  }
  const precedence = parsed.headers.get('precedence');
  if (precedence && /bulk|junk|list/i.test(String(precedence))) {
    return 'Precedence header indicates bulk/automated message';
  }
  if (parsed.headers.get('x-autoreply') || parsed.headers.get('x-autorespond')) {
    return 'X-Autoreply header present';
  }
  if (!parsed.text || parsed.text.trim().length === 0) {
    return 'empty body';
  }
  return null;
}

async function withImapClient<T>(fn: (client: ImapFlow) => Promise<T>): Promise<T> {
  const client = new ImapFlow({
    host: config.IMAP_HOST,
    port: config.IMAP_PORT,
    secure: config.IMAP_TLS,
    auth: { user: config.IMAP_USER, pass: config.IMAP_PASS },
    logger: false,
  });
  await client.connect();
  try {
    return await fn(client);
  } finally {
    await client.logout().catch(() => client.close());
  }
}

export async function fetchUnseenEmails(): Promise<ParsedInbound[]> {
  return withImapClient(async (client) => {
    const lock = await client.getMailboxLock(config.IMAP_MAILBOX);
    const results: ParsedInbound[] = [];
    try {
      const uids = await client.search({ seen: false }, { uid: true });
      if (!uids || uids.length === 0) return results;

      for await (const message of client.fetch(uids, { source: true }, { uid: true }) as AsyncIterable<FetchMessageObject>) {
        try {
          const parsed: ParsedMail = await simpleParser(message.source as Buffer);
          const fromAddr = parsed.from?.value?.[0];
          results.push({
            uid: message.uid,
            messageId: parsed.messageId ?? `no-id-${message.uid}-${Date.now()}`,
            from: fromAddr?.address ?? 'unknown@unknown',
            fromName: fromAddr?.name,
            subject: parsed.subject ?? '(no subject)',
            text: parsed.text ?? '',
            references: Array.isArray(parsed.references) ? parsed.references.join(' ') : parsed.references,
            inReplyTo: parsed.inReplyTo,
            headers: parsed.headers as unknown as Map<string, unknown>,
          });
        } catch (err) {
          logger.error({ err, uid: message.uid }, 'Failed to parse message, skipping');
        }
      }
    } finally {
      lock.release();
    }
    return results;
  });
}

export async function markSeen(uid: number): Promise<void> {
  await withImapClient(async (client) => {
    const lock = await client.getMailboxLock(config.IMAP_MAILBOX);
    try {
      await client.messageFlagsAdd(uid, ['\\Seen'], { uid: true });
    } finally {
      lock.release();
    }
  });
}

export async function markSeenIfApplicable(email: ParsedInbound): Promise<void> {
  if (email.uid >= 0) {
    await markSeen(email.uid).catch((err) => logger.warn({ err }, 'Failed to mark message as seen'));
  }
}

export async function sendReply(params: {
  to: string;
  toName?: string;
  subject: string;
  body: string;
  inReplyTo: string;
  references?: string;
}): Promise<void> {
  const subject = params.subject.toLowerCase().startsWith('re:') ? params.subject : `Re: ${params.subject}`;
  await transporter.sendMail({
    from: `"${config.FROM_NAME}" <${config.FROM_EMAIL}>`,
    to: params.toName ? `"${params.toName}" <${params.to}>` : params.to,
    subject,
    text: `${params.body}\n\n--\n${config.SUPPORT_SIGNATURE}`,
    inReplyTo: params.inReplyTo,
    references: params.references ? `${params.references} ${params.inReplyTo}` : params.inReplyTo,
    headers: {
      // Marks our own reply so other automated systems don't loop with us.
      'Auto-Submitted': 'auto-replied',
    },
  });
}

export async function forwardToHuman(original: ParsedInbound, reason: string): Promise<void> {
  if (!config.ESCALATION_EMAIL) return;
  await transporter.sendMail({
    from: `"${config.FROM_NAME} Bot" <${config.FROM_EMAIL}>`,
    to: config.ESCALATION_EMAIL,
    subject: `[Needs human] ${original.subject}`,
    text: `Escalation reason: ${reason}\n\nFrom: ${original.fromName ?? ''} <${original.from}>\nSubject: ${original.subject}\n\n${original.text}`,
  });
}
```

## `src/pipeline.ts`

```ts
import { ParsedInbound, sendReply, forwardToHuman, markSeenIfApplicable } from './emailClient.js';
import { draftReply } from './llm.js';
import { isAlreadyProcessed, recordProcessed, incrementAndCheckSenderLimit } from './db.js';
import { notifyEscalationWebhook } from './escalation.js';
import { logger } from './logger.js';
import { config } from './config.js';

export async function processInboundEmail(email: ParsedInbound, skipReason: string | null): Promise<void> {
  const log = logger.child({ messageId: email.messageId, from: email.from });

  if (isAlreadyProcessed(email.messageId)) {
    log.info('Already processed, skipping');
    await markSeenIfApplicable(email);
    return;
  }

  if (skipReason) {
    log.info({ skipReason }, 'Skipping inbound email');
    recordProcessed(email.messageId, email.from, email.subject, 'skipped', skipReason);
    await markSeenIfApplicable(email);
    return;
  }

  const withinLimit = incrementAndCheckSenderLimit(email.from, config.MAX_AUTO_REPLIES_PER_SENDER_PER_DAY);
  if (!withinLimit) {
    log.warn('Sender exceeded daily auto-reply limit, escalating');
    await forwardToHuman(email, 'Sender exceeded daily auto-reply rate limit');
    recordProcessed(email.messageId, email.from, email.subject, 'escalated', 'rate limit exceeded');
    await markSeenIfApplicable(email);
    return;
  }

  try {
    const draft = await draftReply({
      messageId: email.messageId,
      from: email.from,
      fromName: email.fromName,
      subject: email.subject,
      text: email.text,
    });

    if (draft.action === 'reply' && draft.replyText) {
      await sendReply({
        to: email.from,
        toName: email.fromName,
        subject: email.subject,
        body: draft.replyText,
        inReplyTo: email.messageId,
        references: email.references,
      });
      recordProcessed(email.messageId, email.from, email.subject, 'replied');
      log.info({ confidence: draft.confidence }, 'Auto-reply sent');
    } else {
      const reason = draft.escalationReason ?? 'Unknown reason';
      await forwardToHuman(email, reason);
      await notifyEscalationWebhook(`Escalated email from ${email.from}: "${email.subject}" — ${reason}`);
      recordProcessed(email.messageId, email.from, email.subject, 'escalated', reason);
      log.info({ reason }, 'Escalated to human');
    }
  } catch (err) {
    log.error({ err }, 'Failed to process email, escalating as a safety fallback');
    await forwardToHuman(email, 'Processing error, needs manual review').catch(() => {});
    recordProcessed(email.messageId, email.from, email.subject, 'failed', String(err));
  } finally {
    await markSeenIfApplicable(email);
  }
}
```

## `src/queue.ts`

```ts
import { Queue, Worker } from 'bullmq';
import IORedis from 'ioredis';
import { config } from './config.js';
import { logger } from './logger.js';
import { processInboundEmail } from './pipeline.js';
import { shouldSkipInbound, ParsedInbound } from './emailClient.js';

const connection = new IORedis(config.REDIS_URL, { maxRetriesPerRequest: null });

export const emailQueue = new Queue<ParsedInbound>('inbound-emails', { connection });

export function startWorker(): Worker<ParsedInbound> {
  const worker = new Worker<ParsedInbound>(
    'inbound-emails',
    async (job) => {
      const skipReason = shouldSkipInbound(job.data);
      await processInboundEmail(job.data, skipReason);
    },
    { connection, concurrency: config.QUEUE_CONCURRENCY },
  );

  worker.on('failed', (job, err) => {
    logger.error({ err, jobId: job?.id }, 'Job failed after retries');
  });

  return worker;
}

export async function enqueueEmail(email: ParsedInbound): Promise<void> {
  await emailQueue.add('process', email, {
    jobId: email.messageId, // dedupes if the same message is enqueued twice
    attempts: 3,
    backoff: { type: 'exponential', delay: 5000 },
    removeOnComplete: 1000,
    removeOnFail: 5000,
  });
}
```

## `src/poller.ts`

```ts
import { fetchUnseenEmails } from './emailClient.js';
import { enqueueEmail } from './queue.js';
import { config } from './config.js';
import { logger } from './logger.js';

let stopped = false;

export function stopPolling(): void {
  stopped = true;
}

export async function startPolling(): Promise<void> {
  logger.info('Starting IMAP poll loop');
  while (!stopped) {
    try {
      const emails = await fetchUnseenEmails();
      if (emails.length) logger.info({ count: emails.length }, 'Fetched unseen emails');
      for (const email of emails) {
        await enqueueEmail(email);
      }
    } catch (err) {
      logger.error({ err }, 'Error during IMAP poll cycle');
    }
    await sleep(config.IMAP_POLL_INTERVAL_MS);
  }
}

function sleep(ms: number) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}
```

## `src/server.ts`

```ts
import express from 'express';
import helmet from 'helmet';
import rateLimit from 'express-rate-limit';
import pinoHttp from 'pino-http';
import { logger } from './logger.js';
import { config } from './config.js';
import { enqueueEmail } from './queue.js';
import type { ParsedInbound } from './emailClient.js';

export function createServer() {
  const app = express();
  app.use(helmet());
  app.use(express.json({ limit: '5mb' }));
  app.use(pinoHttp({ logger }));

  app.get('/healthz', (_req, res) => res.json({ status: 'ok' }));
  app.get('/readyz', (_req, res) => res.json({ status: 'ready' }));

  const webhookLimiter = rateLimit({ windowMs: 60_000, max: 120 });

  // Inbound webhook for providers like Postmark / SendGrid Inbound Parse.
  // Adapt field mapping to whichever provider you use, and verify the
  // provider's signature/secret in production instead of a shared token.
  app.post('/webhooks/inbound-email', webhookLimiter, async (req, res) => {
    if (config.WEBHOOK_SECRET && req.header('x-webhook-token') !== config.WEBHOOK_SECRET) {
      return res.status(401).json({ error: 'unauthorized' });
    }
    try {
      const body = req.body;
      const email: ParsedInbound = {
        uid: -1,
        messageId: body.MessageID ?? body.messageId ?? `${Date.now()}-${Math.random()}`,
        from: body.FromFull?.Email ?? body.from,
        fromName: body.FromFull?.Name ?? body.fromName,
        subject: body.Subject ?? body.subject ?? '(no subject)',
        text: body.TextBody ?? body.text ?? '',
        references: body.References,
        inReplyTo: body.MessageID ?? body.messageId,
        headers: new Map(Object.entries(body.Headers ?? {})),
      };
      await enqueueEmail(email);
      res.status(202).json({ accepted: true });
    } catch (err) {
      req.log.error({ err }, 'Failed to accept inbound webhook');
      res.status(400).json({ error: 'invalid payload' });
    }
  });

  return app;
}
```

## `src/index.ts`

```ts
import { config } from './config.js';
import { logger } from './logger.js';
import { createServer } from './server.js';
import { startWorker } from './queue.js';
import { startPolling, stopPolling } from './poller.js';

async function main() {
  const app = createServer();
  const server = app.listen(config.PORT, () => logger.info(`HTTP server listening on :${config.PORT}`));

  const worker = startWorker();
  const pollingPromise = startPolling();

  const shutdown = async (signal: string) => {
    logger.info({ signal }, 'Shutting down...');
    stopPolling();
    await worker.close();
    server.close();
    process.exit(0);
  };

  process.on('SIGINT', () => shutdown('SIGINT'));
  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('unhandledRejection', (err) => logger.error({ err }, 'Unhandled rejection'));
  process.on('uncaughtException', (err) => {
    logger.error({ err }, 'Uncaught exception');
    process.exit(1);
  });

  await pollingPromise;
}

main().catch((err) => {
  logger.error({ err }, 'Fatal error during startup');
  process.exit(1);
});
```

## Production notes & extension points

1. **Threading context**: currently each reply is generated from a single inbound message. For multi-turn threads, extend `pipeline.ts` to pull prior sent messages (search Sent folder by `References`) and include them in the LLM prompt.
2. **Knowledge base**: replace `knowledgeBase.ts`'s keyword search with embeddings + a vector store once you have more than a few dozen articles.
3. **Webhook auth**: the sample shared-secret check is minimal — implement your provider's real signature verification (Postmark webhook basic auth, SendGrid signed webhooks, etc.) before going live.
4. **PII/compliance**: avoid logging full email bodies in production (only subjects/ids are logged here); add redaction if you log bodies for debugging.
5. **Scaling**: increase `QUEUE_CONCURRENCY` and run multiple worker replicas; BullMQ + Redis handles distribution and retry state across instances.
6. **Model choice**: `response_format: json_object` requires a JSON-mode-capable model (gpt-4o-mini, gpt-4-turbo, gpt-3.5-turbo-1106+).
7. **Human review UI**: for full control, route “reply” drafts to a review queue/dashboard instead of auto-sending until you trust the model's accuracy on your traffic, then relax to full auto-send.
