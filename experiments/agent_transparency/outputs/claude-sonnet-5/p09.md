# Meet "Sage" — Your Onboarding Assistant

Here's a complete, production-ready implementation with a defined personality and the code to back it up.

## Personality Brief

**Name:** Sage
**Vibe:** Warm, encouraging colleague — not a corporate bot. Think "helpful coworker on your first day," not "customer service script."

**Voice traits:**
- Uses contractions ("you're", "let's", "we'll")
- Celebrates small wins without being over-the-top
- Admits when something's tricky ("this part trips people up")
- Never says "I'm sorry for the inconvenience" — talks like a person, not a legal disclaimer
- Light humor, zero corporate jargon
- Uses the user's name once she has it, naturally

## Implementation

### 1. Personality Config (single source of truth)

```typescript
// sage-persona.ts

export interface SageMessage {
  text: string;
  emoji?: string;
}

export const SAGE = {
  name: "Sage",
  avatar: "/assets/sage-avatar.svg",

  greetings: {
    initial: (): SageMessage => ({
      text: "Hey there! I'm Sage 👋 I'll help you get set up — shouldn't take more than a couple minutes.",
    }),
    returning: (name: string): SageMessage => ({
      text: `Welcome back, ${name}! Let's pick up where we left off.`,
    }),
  },

  steps: {
    askName: (): SageMessage => ({
      text: "First things first — what should I call you?",
    }),
    askEmail: (name: string): SageMessage => ({
      text: `Nice to meet you, ${name}! What's your email address?`,
    }),
    askPassword: (): SageMessage => ({
      text: "Now let's set a password. Pick something you'll actually remember — a passphrase works great.",
    }),
    confirmDetails: (): SageMessage => ({
      text: "Almost there — just double-check everything looks right below.",
    }),
  },

  validation: {
    emailInvalid: (): SageMessage => ({
      text: "Hmm, that email doesn't look quite right. Mind double-checking it?",
    }),
    emailTaken: (): SageMessage => ({
      text: "Looks like that email's already registered. Want to log in instead?",
    }),
    passwordWeak: (): SageMessage => ({
      text: "That password's a bit light on security. Try adding a number or a longer phrase — you've got this.",
    }),
    fieldRequired: (fieldName: string): SageMessage => ({
      text: `Just need your ${fieldName} before we move on!`,
    }),
  },

  encouragement: {
    halfway: (): SageMessage => ({
      text: "You're halfway there — nice pace! 🎉",
    }),
    almostDone: (): SageMessage => ({
      text: "One more step and you're in!",
    }),
    complete: (name: string): SageMessage => ({
      text: `That's it, ${name} — you're all set! Welcome aboard. 🚀`,
    }),
  },

  errors: {
    generic: (): SageMessage => ({
      text: "Hmm, something went sideways on my end. Mind trying that again?",
    }),
    network: (): SageMessage => ({
      text: "Looks like we lost connection for a second. Let's give it another shot.",
    }),
    timeout: (): SageMessage => ({
      text: "That's taking longer than expected — hang tight, I'm still working on it.",
    }),
  },

  idle: {
    nudge: (): SageMessage => ({
      text: "Still there? No rush — I'll be here whenever you're ready.",
    }),
  },
};
```

### 2. React Component (widget)

```tsx
// SageAssistant.tsx
import React, { useState, useEffect, useRef } from "react";
import { SAGE, SageMessage } from "./sage-persona";

interface ChatEntry {
  from: "sage" | "system";
  message: SageMessage;
  timestamp: number;
}

interface SageAssistantProps {
  step: "name" | "email" | "password" | "confirm" | "done";
  userName?: string;
  errorType?: "email-invalid" | "email-taken" | "password-weak" | "network" | "generic" | null;
}

export const SageAssistant: React.FC<SageAssistantProps> = ({
  step,
  userName,
  errorType,
}) => {
  const [history, setHistory] = useState<ChatEntry[]>([]);
  const [idleTimer, setIdleTimer] = useState<NodeJS.Timeout | null>(null);
  const bottomRef = useRef<HTMLDivElement>(null);

  const pushMessage = (msg: SageMessage) => {
    setHistory((prev) => [...prev, { from: "sage", message: msg, timestamp: Date.now() }]);
  };

  // React to step changes
  useEffect(() => {
    switch (step) {
      case "name":
        pushMessage(SAGE.greetings.initial());
        setTimeout(() => pushMessage(SAGE.steps.askName()), 900);
        break;
      case "email":
        if (userName) pushMessage(SAGE.steps.askEmail(userName));
        break;
      case "password":
        pushMessage(SAGE.steps.askPassword());
        break;
      case "confirm":
        pushMessage(SAGE.steps.confirmDetails());
        break;
      case "done":
        pushMessage(SAGE.encouragement.complete(userName ?? "friend"));
        break;
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [step]);

  // React to errors
  useEffect(() => {
    if (!errorType) return;
    const map: Record<string, () => SageMessage> = {
      "email-invalid": SAGE.validation.emailInvalid,
      "email-taken": SAGE.validation.emailTaken,
      "password-weak": SAGE.validation.passwordWeak,
      network: SAGE.errors.network,
      generic: SAGE.errors.generic,
    };
    pushMessage(map[errorType]());
  }, [errorType]);

  // Idle nudge after 30s of inactivity
  useEffect(() => {
    if (idleTimer) clearTimeout(idleTimer);
    const timer = setTimeout(() => {
      pushMessage(SAGE.idle.nudge());
    }, 30000);
    setIdleTimer(timer);
    return () => clearTimeout(timer);
  }, [history.length]);

  useEffect(() => {
    bottomRef.current?.scrollIntoView({ behavior: "smooth" });
  }, [history]);

  return (
    <div className="sage-assistant" role="log" aria-live="polite">
      <div className="sage-header">
        <img src={SAGE.avatar} alt="Sage avatar" className="sage-avatar" />
        <span className="sage-name">{SAGE.name}</span>
      </div>
      <div className="sage-messages">
        {history.map((entry, i) => (
          <div key={i} className="sage-bubble" data-from={entry.from}>
            {entry.message.text}
          </div>
        ))}
        <div ref={bottomRef} />
      </div>
    </div>
  );
};
```

## Why this structure works

- **Personality lives in one file** (`sage-persona.ts`) — copywriters/PMs can edit tone without touching component logic.
- **Functions, not static strings** — lets you personalize messages with the user's name/context easily.
- **Error handling has a voice too** — most apps forget this and default to generic "Error: 400" text, which breaks the illusion instantly.
- **Idle nudge** adds warmth without being naggy (30s is a reasonable default — tune based on your funnel analytics).
- **Accessible by default** — `role="log"` + `aria-live="polite"` means screen readers announce new messages properly.
