# Dental Practice Phone-Answering Bot — Production Architecture & Code

This is a complete, deployable reference implementation. It uses **Twilio Voice + `<Gather>` speech recognition** (Twilio's built-in STT/TTS) as the primary transport — it's the most reliable, lowest-risk way to ship a production phone bot. At the end I describe the upgrade path to **Twilio Media Streams + a realtime speech-to-speech model** for lower latency once the basic flow is validated.

---

## 1. Architecture

```
Caller ──PSTN──> Twilio Number ──Webhook(HTTPS)──> FastAPI App
                                                     │
                                    ┌────────────────┼─────────────────┐
                                    │                │                 │
                              Redis (call state)  OpenAI API      PostgreSQL
                              (conversation ctx,   (dialogue +    (patients,
                               TTL ~15min)          tool calls)    appointments,
                                                                    call logs)
                                    │
                              Twilio REST API
                              (SMS confirmation,
                               call transfer/dial)
```

**Call flow per turn:**
1. Twilio POSTs speech transcript to our webhook.
2. We load conversation state from Redis, append the user turn.
3. We call the LLM with function-calling tools (`check_availability`, `book_appointment`, `transfer_to_staff`, `end_call`).
4. Tool calls hit Postgres (with row/transaction locking to prevent double-booking).
5. We return TwiML: `<Say>` the reply, then either re-`<Gather>`, `<Dial>` to a human, or `<Hangup>`.
6. On booking, we fire a confirmation SMS via Twilio REST API.

## 6. Scheduling engine (double-booking safe)

```python
# app/scheduling.py
import datetime as dt
import secrets
import string
from sqlalchemy import select, text
from sqlalchemy.ext.asyncio import AsyncSession
from app.models import Provider, Appointment, Patient
from app.config import settings

APPOINTMENT_DURATIONS = {
    "checkup": 30,
    "cleaning": 60,
    "filling": 45,
    "consultation": 30,
    "emergency": 30,
    "whitening": 45,
}

# Monday=0 ... Sunday=6 -> (open_hour, close_hour) or None if closed
BUSINESS_HOURS = {
    0: (8, 17), 1: (8, 17), 2: (8, 17), 3: (8, 17), 4: (8, 17),
    5: (9, 13), 6: None,
}

SLOT_GRANULARITY_MIN = 30


class SlotUnavailableError(Exception):
    pass


def within_business_hours(now: dt.datetime | None = None) -> bool:
    now = now or dt.datetime.now(settings.tz)
    hours = BUSINESS_HOURS.get(now.weekday())
    if not hours:
        return False
    return hours[0] <= now.hour < hours[1]


def generate_confirmation_code(n: int = 6) -> str:
    alphabet = string.ascii_uppercase + string.digits
    return "".join(secrets.choice(alphabet) for _ in range(n))


async def _provider_is_free(session: AsyncSession, provider_id: int, start: dt.datetime, duration_min: int) -> bool:
    end = start + dt.timedelta(minutes=duration_min)
    result = await session.execute(
        select(Appointment.id).where(
            Appointment.provider_id == provider_id,
            Appointment.status != "cancelled",
            Appointment.start_time < end,
            Appointment.end_time > start,
        )
    )
    return result.first() is None


async def find_available_slots(
    session: AsyncSession,
    appointment_type: str,
    earliest: dt.datetime,
    latest: dt.datetime,
    max_results: int = 5,
) -> list[dict]:
    duration = APPOINTMENT_DURATIONS.get(appointment_type, 30)
    providers = (await session.execute(select(Provider))).scalars().all()
    if not providers:
        return []

    slots: list[dict] = []
    day = earliest.date()
    while day <= latest.date() and len(slots) < max_results:
        hours = BUSINESS_HOURS.get(day.weekday())
        if hours:
            open_h, close_h = hours
            cursor = dt.datetime.combine(day, dt.time(open_h, 0), tzinfo=settings.tz)
            day_end = dt.datetime.combine(day, dt.time(close_h, 0), tzinfo=settings.tz)
            while cursor + dt.timedelta(minutes=duration) <= day_end and len(slots) < max_results:
                if cursor >= earliest:
                    for provider in providers:
                        if await _provider_is_free(session, provider.id, cursor, duration):
                            slots.append({
                                "provider_id": provider.id,
                                "provider_name": provider.name,
                                "start_iso": cursor.isoformat(),
                                "display": cursor.strftime("%A, %B %d at %-I:%M %p"),
                            })
                            break
                cursor += dt.timedelta(minutes=SLOT_GRANULARITY_MIN)
        day += dt.timedelta(days=1)
    return slots


async def get_or_create_patient(
    session: AsyncSession, first_name: str, last_name: str, dob: dt.date, phone: str
) -> Patient:
    result = await session.execute(
        select(Patient).where(Patient.phone == phone, Patient.dob == dob)
    )
    patient = result.scalar_one_or_none()
    if patient:
        return patient
    patient = Patient(first_name=first_name, last_name=last_name, dob=dob, phone=phone)
    session.add(patient)
    await session.flush()
    return patient


async def book_appointment(
    session: AsyncSession,
    provider_id: int,
    patient: Patient,
    appointment_type: str,
    start_time: dt.datetime,
    notes: str = "",
) -> Appointment:
    duration = APPOINTMENT_DURATIONS.get(appointment_type, 30)
    end_time = start_time + dt.timedelta(minutes=duration)

    # Postgres transaction-scoped advisory lock keyed on provider+slot prevents
    # a race between two simultaneous booking attempts for the same slot.
    lock_key = abs(hash(f"{provider_id}:{start_time.isoformat()}")) % (2**63)
    await session.execute(text("SELECT pg_advisory_xact_lock(:key)"), {"key": lock_key})

    if not await _provider_is_free(session, provider_id, start_time, duration):
        raise SlotUnavailableError(f"Slot {start_time} with provider {provider_id} is no longer available.")

    appt = Appointment(
        patient_id=patient.id,
        provider_id=provider_id,
        appointment_type=appointment_type,
        start_time=start_time,
        end_time=end_time,
        status="booked",
        notes=notes,
        confirmation_code=generate_confirmation_code(),
    )
    session.add(appt)
    await session.commit()
    return appt
```

# app/prompts.py
import datetime as dt
from app.config import settings
from app.scheduling import APPOINTMENT_DURATIONS, BUSINESS_HOURS


def _hours_text() -> str:
    days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
    parts = []
    for i, d in enumerate(days):
        h = BUSINESS_HOURS.get(i)
        parts.append(f"{d}: {h[0]}:00-{h[1]}:00" if h else f"{d}: closed")
    return ", ".join(parts)


def build_system_prompt() -> str:
    now = dt.datetime.now(settings.tz)
    return f"""You are Ava, the AI phone receptionist for {settings.office_name}, a dental practice
located at {settings.office_address}. You are speaking with a caller over the PHONE — keep every
reply short (1-2 sentences), natural, and easy to understand when spoken aloud. Do not use lists,
markdown, or symbols.

Current date/time at the office: {now.strftime('%A, %Y-%m-%d %H:%M')} ({settings.office_timezone}).
Office hours: {_hours_text()}.
Appointment types you can book: {", ".join(APPOINTMENT_DURATIONS.keys())}.

Your job:
1. Help callers book, and only book, dental appointments. You may also answer basic questions about
   office hours, address, and accepted insurance in general terms.
2. Before booking, you MUST collect: full name, date of birth, a callback phone number, and the
   appointment type/reason.
3. Always call the `check_availability` tool to get real open slots — NEVER invent or guess a time.
4. Offer at most 3 concrete options from the tool result and ask the caller to pick one.
5. Before calling `book_appointment`, read back the full name, date of birth, phone number, and the
   chosen date/time, and get explicit confirmation ("yes"/"that's right").
6. If the caller describes a dental emergency (uncontrolled bleeding, facial swelling affecting
   breathing/swallowing, trauma, knocked-out tooth, severe unbearable pain), do NOT try to schedule
   normally — call `transfer_to_staff` immediately and tell the caller you are connecting them to a
   team member right away. If it sounds life-threatening, advise them to hang up and call 911 or go
   to the ER.
7. Never provide clinical/medical advice (e.g., what medication to take, diagnosis). Politely defer
   those questions to the dentist and offer to book a visit or transfer the call.
8. If the caller asks for a human, is frustrated, or you cannot help, call `transfer_to_staff`.
9. When the caller's request is fully resolved and they have nothing else to ask, call `end_call`.
10. If the caller wants to cancel or change an existing appointment, use `transfer_to_staff` unless
    you have looked them up and confirmed the appointment yourself.

Never make up information about insurance coverage, pricing, or clinical matters. Stay warm,
professional, and concise at all times.
"""
```

# app/llm.py
import json
import datetime as dt
from dataclasses import dataclass, field
from openai import AsyncOpenAI
from app.config import settings

TOOLS_SCHEMA = [

        "type": "function",

    },

        "function": {
            "name": "book_appointment",
            "description": "Book a confirmed appointment. Only call after the caller verbally "
                            "confirmed name, date of birth, phone number, and exact slot.",
            "parameters": {
                "type": "object",
                "properties": {
                    "first_name": {"type": "string"},
                    "last_name": {"type": "string"},
                    "date_of_birth": {"type": "string", "description": "ISO date YYYY-MM-DD"},
                    "phone_number": {"type": "string"},
                    "appointment_type": {
                        "type": "string",
                        "enum": ["checkup", "cleaning", "filling", "consultation", "emergency", "whitening"],
                    },
                    "provider_id": {"type": "integer"},
                    "slot_start_iso": {"type": "string", "description": "Exact ISO datetime from check_availability"},
                    "notes": {"type": "string"},
                },
                "required": [
                    "first_name", "last_name", "date_of_birth", "phone_number",
                    "appointment_type", "provider_id", "slot_start_iso",
                ],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "transfer_to_staff",
            "description": "Transfer the call to a live human staff member.",
            "parameters": {
                "type": "object",
                "properties": {"reason": {"type": "string"}},
                "required": ["reason"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "end_call",
            "description": "End the call politely once the caller's request is resolved.",
            "parameters": {
                "type": "object",
                "properties": {"summary": {"type": "string"}},
                "required": ["summary"],
            },
        },
    },
]


@dataclass
class LLMTurnResult:
    assistant_text: str
    messages: list[dict]
    action: str = "continue"  # continue | transfer | end
    booking_confirmation: dict | None = None


async def _execute_tool(name: str, args: dict) -> tuple[dict, str | None]:
    """Returns (payload_for_model, action_override)."""
    if name == "check_availability":
        async with async_session() as session:
            earliest = dt.datetime.fromisoformat(args["earliest_date"]).replace(tzinfo=settings.tz)
            latest = dt.datetime.fromisoformat(args["latest_date"]).replace(tzinfo=settings.tz)
            now = dt.datetime.now(settings.tz)
            earliest = max(earliest, now)
            slots = await find_available_slots(session, args["appointment_type"], earliest, latest)
            return {"slots": slots}, None

    if name == "book_appointment":
        async with async_session() as session:
            try:
                dob = dt.date.fromisoformat(args["date_of_birth"])
                patient = await get_or_create_patient(
                    session, args["first_name"], args["last_name"], dob, args["phone_number"]
                )
                start_time = dt.datetime.fromisoformat(args["slot_start_iso"])
                if start_time.tzinfo is None:
                    start_time = start_time.replace(tzinfo=settings.tz)
                appt = await book_appointment(
                    session, args["provider_id"], patient, args["appointment_type"],
                    start_time, args.get("notes", ""),
                )
                payload = {
                    "status": "booked",
                    "confirmation_code": appt.confirmation_code,
                    "start_time": appt.start_time.isoformat(),
                }
                return payload, None
            except SlotUnavailableError:
                return {"status": "failed", "reason": "slot_no_longer_available"}, None

    if name == "transfer_to_staff":
        return {"status": "transferring"}, "transfer"

    if name == "end_call":
        return {"status": "ending"}, "end"

    return {"status": "unknown_tool"}, None


async def run_llm_turn(state: ConversationState) -> LLMTurnResult:
    # Keep the system prompt fresh with current date/time every turn.
    if not state.messages or state.messages[0].get("role") != "system":
        state.messages.insert(0, {"role": "system", "content": build_system_prompt()})
    else:
        state.messages[0] = {"role": "system", "content": build_system_prompt()}

    messages = state.messages
    action = "continue"
    booking_confirmation = None

    for _ in range(5):  # bounded tool-call loop
        response = await client.chat.completions.create(
            model=settings.openai_model,
            messages=messages,
            tools=TOOLS_SCHEMA,
            tool_choice="auto",
            temperature=0.3,
        )
        msg = response.choices[0].message
        msg_dict = msg.model_dump(exclude_none=True)
        msg_dict.setdefault("content", None)
        messages.append(msg_dict)

        if msg.tool_calls:
            for tool_call in msg.tool_calls:
                args = json.loads(tool_call.function.arguments or "{}")
                payload, action_override = await _execute_tool(tool_call.function.name, args)
                if tool_call.function.name == "book_appointment" and payload.get("status") == "booked":
                    booking_confirmation = payload
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": json.dumps(payload),
                })
                if action_override:
                    action = action_override
            continue  # let the model produce a final reply using the tool result

        return LLMTurnResult(
            assistant_text=msg.content or "Sorry, could you say that again?",
            messages=messages,
            action=action,
            booking_confirmation=booking_confirmation,
        )

    return LLMTurnResult(
        assistant_text="Let me connect you with our front desk to finish up.",
        messages=messages,
        action="transfer",
        booking_confirmation=booking_confirmation,
    )

# app/twilio_utils.py
from fastapi import Request, HTTPException
from twilio.request_validator import RequestValidator
from twilio.twiml.voice_response import VoiceResponse, Gather
from app.config import settings

GATHER_VOICE = "Polly.Joanna-Neural"


async def validate_twilio_request(request: Request) -> dict:
    form = await request.form()
    form_dict = dict(form)

    if settings.testing:
        return form_dict

    signature = request.headers.get("X-Twilio-Signature", "")
    validator = RequestValidator(settings.twilio_auth_token)
    # Reconstruct the exact public URL Twilio signed (must match TwiML app config).
    url = f"{settings.public_base_url}{request.url.path}"
    if not validator.validate(url, form_dict, signature):
        raise HTTPException(status_code=403, detail="Invalid Twilio signature")
    return form_dict


def build_gather(action: str) -> Gather:
    return Gather(
        input="speech",
        action=action,
        method="POST",
        speech_timeout="auto",
        speech_model="phone_call",
        language="en-US",
        action_on_empty_result=True,
        barge_in=True,
    )


def xml_response(vr: VoiceResponse):
    from fastapi import Response
    return Response(content=str(vr), media_type="application/xml")
```

@app.post("/voice/gather")
async def voice_gather(request: Request):
    form = await validate_twilio_request(request)
    call_sid = form["CallSid"]
    speech_result = (form.get("SpeechResult") or "").strip()

    vr = VoiceResponse()
    state = await load_state(call_sid)

    if state is None:
        # Session expired / server restarted mid-call — restart the conversation once.
        vr.redirect("/voice/incoming")
        return xml_response(vr)

    if not speech_result:
        state.no_input_count += 1
        if state.no_input_count > settings.max_no_input_retries:
            vr.say("I'm having trouble hearing you. Let me connect you with our front desk.",
                   voice="Polly.Joanna-Neural")
            vr.dial(settings.office_transfer_number)
            await _end_call_log(call_sid, "transferred_no_input", state.messages)
            await delete_state(call_sid)
            return xml_response(vr)

        vr.say("Sorry, I didn't catch that — could you say that again?", voice="Polly.Joanna-Neural")
        gather = build_gather(action="/voice/gather")
        vr.append(gather)
        await save_state(state)
        return xml_response(vr)

    state.no_input_count = 0
    state.turn_count += 1
    state.messages.append({"role": "user", "content": speech_result})

    try:
        result = await run_llm_turn(state)
    except Exception:
        logger.exception("LLM turn failed for call %s", call_sid)
        vr.say("I'm sorry, I'm having a technical issue. Let me connect you with our staff.",
               voice="Polly.Joanna-Neural")
        vr.dial(settings.office_transfer_number)
        await _end_call_log(call_sid, "error_transfer", state.messages)
        await delete_state(call_sid)
        return xml_response(vr)

    state.messages = result.messages
    await save_state(state)

    vr.say(result.assistant_text, voice="Polly.Joanna-Neural")

    if result.booking_confirmation:
        try:
            await send_confirmation_sms(
                to=state.from_number,
                confirmation_code=result.booking_confirmation["confirmation_code"],
                when_display=result.booking_confirmation["start_time"],
            )
        except Exception:
            logger.exception("Failed to send confirmation SMS for call %s", call_sid)

    if result.action == "transfer":
        vr.dial(settings.office_transfer_number)
        await _end_call_log(call_sid, "transferred", state.messages)
        await delete_state(call_sid)
    elif result.action == "end":
        vr.hangup()
        await _end_call_log(call_sid, "completed", state.messages)
        await delete_state(call_sid)
    else:
        gather = build_gather(action="/voice/gather")
        vr.append(gather)

    return xml_response(vr)


@app.post("/voice/status")
async def voice_status(request: Request):
    """Twilio call status callback (ringing/answered/completed/etc.)."""
    form = await validate_twilio_request(request)
    call_sid = form.get("CallSid")
    call_status = form.get("CallStatus")
    if call_status in ("completed", "busy", "no-answer", "failed", "canceled"):
        async with async_session() as session:
            await session.execute(
                update(CallLog)
                .where(CallLog.call_sid == call_sid, CallLog.ended_at.is_(None))
                .values(ended_at=dt.datetime.utcnow(), outcome=call_status)
            )
            await session.commit()
    return {"status": "received"}


async def _log_call_start(call_sid: str, from_number: str, outcome: str | None = None):
    async with async_session() as session:
        session.add(CallLog(call_sid=call_sid, from_number=from_number, outcome=outcome,
                             ended_at=dt.datetime.utcnow() if outcome else None))
        await session.commit()


async def _end_call_log(call_sid: str, outcome: str, messages: list[dict]):
    # Strip the system prompt / tool schemas before persisting for QA review.
    sanitized = [m for m in messages if m.get("role") in ("user", "assistant") and m.get("content")]
    async with async_session() as session:
        await session.execute(
            update(CallLog)
            .where(CallLog.call_sid == call_sid)
            .values(ended_at=dt.datetime.utcnow(), outcome=outcome, transcript={"turns": sanitized})
        )
        await session.commit()

## 13. Compliance & safety checklist (important — don't skip)

- **HIPAA**: Names, DOB, phone numbers, appointment reasons are PHI. You need a signed **BAA with Twilio** (available on qualifying accounts) and with **OpenAI** (enterprise agreement / API with zero data retention). Do not use consumer ChatGPT accounts.
- **Call recording disclosure**: Many states require notifying callers a call may be recorded (included in the greeting above). Verify against your state's two-party consent rules.
- **Data minimization**: Store DOB/phone only as needed; encrypt the database at rest (cloud-managed Postgres with encryption, or `pgcrypto` for column-level encryption on `dob`/`phone`).
- **Emergency handling**: The system prompt forces a transfer on emergency keywords, but you should also add a regex safety net (e.g., "can't breathe", "severe bleeding") that force-transfers *before* even calling the LLM, as a backstop against model failure.
- **Access control**: Restrict DB/Redis network access to the app only; rotate Twilio auth tokens and OpenAI keys via a secrets manager (AWS Secrets Manager / Vault), not `.env` in production.
- **Idempotency**: Twilio may retry webhooks on timeout — booking is protected by the Postgres advisory lock + a duplicate check, but consider also de-duping on `CallSid` + tool-call id if you see double SMS sends.
- **Fallback to humans**: Always keep a real front-desk line reachable (`office_transfer_number`), and make sure the bot transfers gracefully on repeated failures, technical errors, or explicit request.

## 14. Upgrading to lower latency (Media Streams / realtime speech)

The `<Gather>`-based flow above has ~2-4s of turn latency (Twilio STT → webhook → LLM → TTS), which is fine for scheduling but not "instant." To reduce this:

1. Switch the Twilio webhook to return `<Connect><Stream url="wss://.../media"/></Connect>` instead of `<Gather>`.
2. Open a WebSocket endpoint that receives 8kHz mulaw audio frames from Twilio in real time.
3. Bridge that audio to **OpenAI's Realtime API** (speech-to-speech, function calling built in) or a Deepgram (STT) → GPT-4o (dialogue) → ElevenLabs (streaming TTS) pipeline, streaming audio frames back to Twilio as they're generated (barge-in supported).
4. Reuse the exact same `TOOLS_SCHEMA` and tool-execution functions (`check_availability`, `book_appointment`, etc.) from `app/llm.py` — only the transport layer changes.

This is a larger, stateful WebSocket implementation (audio resampling, VAD, backpressure handling) — worth doing once call volume justifies the added complexity and after the Gather-based version has validated the conversation design and prompts in production.
