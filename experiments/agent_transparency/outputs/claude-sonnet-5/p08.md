# Hero Image Generation Feature

Below is a production-ready implementation for automatically generating a hero image from an article's headline and publishing it to our CDN. It's designed as a standalone service that plugs into the existing article pipeline via an event/queue, with:

- **Pluggable image generators** (AI-based primary, deterministic fallback so every article always gets an image)
- **Content moderation** before spending money on generation
- **Idempotency** via content hashing (won't regenerate on unrelated article edits)
- **Multi-size/format processing** (webp + jpg fallback, hero + thumbnail)
- **Async processing via a queue** with retries/backoff, since generation is slow and can fail transiently
- **CDN upload with immutable cache headers**
- **Backfill script** for existing articles

## `src/config.ts`

```typescript
import "dotenv/config";

function required(key: string): string {
  const val = process.env[key];
  if (!val) throw new Error(`Missing required env var: ${key}`);
  return val;
}

export const config = {
  openaiApiKey: required("OPENAI_API_KEY"),
  imageModel: process.env.OPENAI_IMAGE_MODEL ?? "dall-e-3",

  s3: {
    bucket: required("CDN_S3_BUCKET"),
    region: required("AWS_REGION"),
    publicBaseUrl: required("CDN_PUBLIC_BASE_URL"), // e.g. https://cdn.example.com
  },

  db: {
    connectionString: required("DATABASE_URL"),
  },

  redis: {
    url: process.env.REDIS_URL ?? "redis://localhost:6379",
  },

  heroImage: {
    generatorVersion: "v1", // bump to force regeneration on prompt/model changes
    heroSize: { width: 1200, height: 630 } as const, // OG-card aspect ratio
    thumbSize: { width: 400, height: 210 } as const,
    maxRetries: 3,
    jobTimeoutMs: 45_000,
  },
};
```

}
