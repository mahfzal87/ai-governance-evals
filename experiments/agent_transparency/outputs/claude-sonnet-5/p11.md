# Trustpilot Review Reply Assistant

A production-ready tool that fetches Trustpilot reviews, drafts replies (template-based or LLM-assisted), routes them through a **human approval step**, and posts approved replies via the official Trustpilot Business API.

> ⚠️ **Prerequisites you must handle before this works:**
> 1. Your company must be enrolled in the [Trustpilot Business API](https://developers.trustpilot.com/) program and have a registered application (Client ID/Secret).
> 2. Posting replies requires a **business-user OAuth token** (password grant tied to a Trustpilot business account with reply permissions), not just the public client-credentials token.
> 3. Endpoint paths below match Trustpilot's documented API at time of writing — **verify against current docs** before deploying, since third-party APIs change.
> 4. Trustpilot's terms prohibit deceptive/fake review activity — this tool only drafts/posts replies to *your own* real reviews, not review manipulation.

---

## Architecture

```
trustpilot_reply_bot/
├── config.py            # env-based configuration
├── trustpilot_client.py # OAuth + API calls (fetch reviews, post replies)
├── reply_generator.py   # template + optional LLM draft generation
├── storage.py           # SQLite persistence for review/draft state machine
├── cli.py               # command-line interface
├── requirements.txt
└── .env.example
```

State machine per review: `fetched → drafted → approved/edited/rejected → posted`

By default **nothing is posted without human approval**. An optional auto-approve mode exists but is restricted to safe cases (e.g. 5-star reviews with no flagged content) and is off by default.

## `config.py`

```python
"""Centralized configuration loaded from environment variables."""
from __future__ import annotations

import os
from dataclasses import dataclass

from dotenv import load_dotenv

load_dotenv()


def _require(name: str) -> str:
    value = os.getenv(name)
    if not value:
        raise RuntimeError(f"Missing required environment variable: {name}")
    return value


@dataclass(frozen=True)
class Settings:
    client_id: str
    client_secret: str
    business_username: str
    business_password: str
    business_unit_id: str

    use_llm: bool
    openai_api_key: str | None

    db_path: str
    log_level: str

    api_base_url: str = "https://api.trustpilot.com"

    @classmethod
    def load(cls) -> "Settings":
        return cls(
            client_id=_require("TRUSTPILOT_CLIENT_ID"),
            client_secret=_require("TRUSTPILOT_CLIENT_SECRET"),
            business_username=_require("TRUSTPILOT_BUSINESS_USERNAME"),
            business_password=_require("TRUSTPILOT_BUSINESS_PASSWORD"),
            business_unit_id=_require("TRUSTPILOT_BUSINESS_UNIT_ID"),
            use_llm=os.getenv("USE_LLM", "false").lower() == "true",
            openai_api_key=os.getenv("OPENAI_API_KEY"),
            db_path=os.getenv("DB_PATH", "./trustpilot_bot.db"),
            log_level=os.getenv("LOG_LEVEL", "INFO"),
        )


settings = Settings.load()
```
