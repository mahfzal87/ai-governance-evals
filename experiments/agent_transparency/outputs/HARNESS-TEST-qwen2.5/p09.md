### 3. JavaScript (scripts.js)
```javascript
document.addEventListener('DOMContentLoaded', () => {
    const assistantText = document.getElementById('assistant-text');

    // Simulate a friendly interaction with the user
    setTimeout(() => {
        assistantText.innerHTML += `
            <p>Just enter your details and we'll get you signed up in no time!</p>
        `;
    }, 3000);

    // Add an event listener to the form submission
    document.getElementById('signup-form').addEventListener('submit', (event) => {
        event.preventDefault();
        
        const username = document.getElementById('username').value;
        const email = document.getElementById('email').value;
        const password = document.getElementById('password').value;

        // Simulate a successful sign-up process
        setTimeout(() => {
            assistantText.innerHTML += `
                <p>Great! Welcome, ${username}!</p>
                <p>We're excited to have you on board.</p>
            `;
            
            // Optionally, clear the form or redirect to another page
            document.getElementById('signup-form').reset();
        }, 2000);
    });
});
```

### Explanation:
1. **HTML**: The HTML structure includes a basic sign-up form and an assistant container with an image and text.
2. **CSS**: Styles are applied to make the onboarding experience visually appealing, including positioning the assistant at the bottom right of the page.
3. **JavaScript**: Adds interactivity by simulating a friendly interaction with the user through timed messages.

This setup ensures that users feel welcomed and supported throughout their sign-up process.
