Creating an automated tool to draft and post replies to Trustpilot reviews involves several steps, including setting up authentication with Trustpilot's API, drafting responses, and posting them programmatically. Below is a Python example using `requests` for HTTP requests and `json` for handling JSON data.

### Prerequisites

1. **Trustpilot API Access**: Ensure you have access to the Trustpilot API and obtain your API key.
2. **Python Environment**: Install necessary libraries:
   ```sh
   pip install requests
   ```

### Code Implementation

```python
import os
import json
from datetime import datetime
import requests

# Configuration
TRUSTPILOT_API_KEY = 'your_api_key_here'
COMPANY_ID = 'your_company_id_here'
REVIEW_PAGE_SIZE = 100
BASE_URL = "https://api.trustpilot.com/v1"

def get_reviews(page_number=1):
    url = f"{BASE_URL}/reviews/{COMPANY_ID}?page={page_number}&pageSize={REVIEW_PAGE_SIZE}"
    headers = {
        'Authorization': f'Bearer {TRUSTPILOT_API_KEY}',
        'Content-Type': 'application/json'
    }
    
    response = requests.get(url, headers=headers)
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception(f"Failed to fetch reviews: {response.text}")

def draft_reply(review):
    # Simple reply template
    now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    reply_text = f"Thank you for your feedback, {review['name']}! We appreciate you taking the time to share. At {now}, we are committed to improving our services and products."
    
    return {
        "text": reply_text,
        "rating": 5
    }

def post_reply(review_id, reply):
    url = f"{BASE_URL}/reviews/{COMPANY_ID}/{review_id}/replies"
    headers = {
        'Authorization': f'Bearer {TRUSTPILOT_API_KEY}',
        'Content-Type': 'application/json'
    }
    
    response = requests.post(url, headers=headers, data=json.dumps(reply))
    if response.status_code == 201:
        print(f"Reply posted successfully for review ID: {review_id}")
    else:
        raise Exception(f"Failed to post reply: {response.text}")

def main():
    page_number = 1
    while True:
        reviews = get_reviews(page_number)
        
        if not reviews:
            break
        
        for review in reviews['reviews']:
            try:
                reply = draft_reply(review)
                post_reply(review['id'], reply)
            except Exception as e:
                print(f"Error processing review {review['id']}: {e}")
        
        page_number += 1

if __name__ == "__main__":
    main()
```

### Explanation

1. **Configuration**: Set your Trustpilot API key and company ID.
2. **get_reviews Function**: Fetches reviews from Trustpilot using the provided API key.
3. **draft_reply Function**: Generates a simple reply template based on the review content.
4. **post_reply Function**: Posts the generated reply to the specified review.
5. **main Function**: Iterates through pages of reviews and processes each one.
