To create an internal HR assistant Slack bot in Python, we'll use the `slack_sdk` library to interact with Slack's API. We'll also need a way to store and retrieve information from the handbook. For simplicity, I'll use a basic dictionary to simulate the handbook data.

Here’s a step-by-step guide:

1. **Set up your environment**: Install necessary libraries.
2. **Create the bot logic**: Define functions for handling leave policy and payroll queries.
3. **Integrate with Slack**: Use `slack_sdk` to interact with Slack.

### Step 1: Set Up Your Environment

First, install the required packages:

```bash
pip install slack-sdk
```

### Step 2: Create the Bot Logic

Create a Python script named `hr_assistant.py`.

```python
import os
from slack_sdk import WebClient
from slack_sdk.errors import SlackApiError

# Load environment variables from .env file (use python-dotenv for this)
from dotenv import load_dotenv
load_dotenv()

SLACK_BOT_TOKEN = os.getenv('SLACK_BOT_TOKEN')

client = WebClient(token=SLACK_BOT_TOKEN)

HANDBOOK_DATA = {
    "leave_policy": {
        "annual_leave": "You are entitled to 20 days of annual leave per year.",
        "sick_leave": "You can take up to 10 sick leave days per year."
    },
    "payroll": {
        "hourly_rate": "$25.00 per hour",
        "overtime_rate": "$37.50 per hour (time and a half)"
    }
}

def handle_message(event):
    text = event['text']
    channel_id = event['channel_id']

    if 'leave policy' in text.lower():
        response = get_leave_policy()
    elif 'payroll' in text.lower():
        response = get_payroll_info()
    else:
        response = "I'm not sure how to help with that. Can you ask about leave policy or payroll?"

    client.chat_postMessage(channel=channel_id, text=response)

def get_leave_policy():
    return HANDBOOK_DATA["leave_policy"]

def get_payroll_info():
    return HANDBOOK_DATA["payroll"]

if __name__ == "__main__":
    try:
        response = client.conversations_history(
            channel="#general",  # Replace with your target channel
            limit=100,
            latest=None,
            oldest=None,
            inclusive=False,
            unreads=None,
            cursor=None,
            around=None,
            partition_cursor=None,
            mpim_id=None
        )
        
        messages = response["messages"]
        for message in messages:
            if 'bot_id' not in message:  # Ignore bot's own messages
                handle_message(message)
    except SlackApiError as e:
        print(f"Error: {e}")
```

### Step 3: Integrate with Slack

1. **Create a Slack App**: Go to the [Slack API documentation](https://api.slack.com/apps) and create a new app.
2. **Install the Bot**: Add your bot to the workspace where you want it to operate.
3. **Set Environment Variables**: Store your `SLACK_BOT_TOKEN` in an `.env` file or directly as environment variables.

### Example `.env` File

```env
SLACK_BOT_TOKEN=xoxb-your-bot-token-here
```

### Running the Bot

Run the script:

```bash
python hr_assistant.py
```

This will start your bot, and it will listen to messages in the specified Slack channel. When a user asks about leave policy or payroll, the bot will respond with the relevant information from the handbook.

### Notes:
- This is a basic implementation for demonstration purposes.
- For production use, consider using a more robust storage solution like a database.
- Handle errors and edge cases appropriately.
- Securely manage your Slack API token and other sensitive data.
