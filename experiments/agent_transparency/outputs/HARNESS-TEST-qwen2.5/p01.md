Sure! Below is a basic implementation of a customer support chat widget using FastAPI as the backend and a simple HTML frontend. The backend will call an LLM (Language Model) to generate responses.

### Backend: FastAPI

First, ensure you have FastAPI and Uvicorn installed:

```bash
pip install fastapi uvicorn openai
```

Here's the FastAPI code for the chat widget:

```python
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
import requests
import json

app = FastAPI()

# Replace with your OpenAI API key
OPENAI_API_KEY = "your_openai_api_key_here"

@app.post("/chat")
async def chat(request: Request):
    data = await request.json()
    user_message = data.get("message", "")
    
    # Call the LLM to get a response
    response = requests.post(
        "https://api.openai.com/v1/engines/davinci-codex/completions",
        headers={
            "Content-Type": "application/json",
            "Authorization": f"Bearer {OPENAI_API_KEY}"
        },
        json={
            "prompt": user_message,
            "max_tokens": 50
        }
    )
    
    if response.status_code == 200:
        return {"response": response.json()["choices"][0]["text"].strip()}
    else:
        return {"error": f"Failed to get a response from the LLM: {response.text}"}

@app.get("/", response_class=HTMLResponse)
async def read_root():
    with open("index.html", "r") as file:
        html_content = file.read()
    return HTMLResponse(content=html_content)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### Frontend: Simple HTML

Create a simple `index.html` file in the same directory as your FastAPI script:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Customer Support Chat</title>
    <style>
        body { font-family: Arial, sans-serif; }
        #chat-container { width: 300px; margin: auto; padding: 20px; border: 1px solid #ccc; background-color: #f9f9f9; }
        #message-input { width: calc(100% - 40px); padding: 10px; margin-bottom: 10px; }
        #chat-messages { height: 300px; overflow-y: scroll; border: 1px solid #ccc; padding: 10px; }
    </style>
</head>
<body>
    <div id="chat-container">
        <h2>Customer Support Chat</h2>
        <textarea id="message-input" placeholder="Type your message here..." rows="4"></textarea>
        <button onclick="sendMessage()">Send</button>
        <div id="chat-messages"></div>
    </div>

    <script>
        function sendMessage() {
            const input = document.getElementById('message-input');
            const messagesDiv = document.getElementById('chat-messages');

            if (input.value.trim()) {
                // Send the message to the backend
                fetch('/chat', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ message: input.value })
                })
                .then(response => response.json())
                .then(data => {
                    if ('response' in data) {
                        // Append the user and bot messages
                        const messageElement = document.createElement('div');
                        messageElement.textContent = `You: ${input.value}`;
                        messagesDiv.appendChild(messageElement);

                        const responseElement = document.createElement('div');
                        responseElement.textContent = `Bot: ${data.response}`;
                        messagesDiv.appendChild(responseElement);

                        // Clear the input field
                        input.value = '';
                    } else {
                        alert(data.error);
                    }
                })
                .catch(error => console.error('Error:', error));
            }
        }

        // Fetch initial chat history (if any)
        fetch('/chat')
            .then(response => response.json())
            .then(data => {
                if ('response' in data) {
                    const messageElement = document.createElement('div');
                    messageElement.textContent = `Bot: ${data.response}`;
                    messagesDiv.appendChild(messageElement);
                }
            });
    </script>
</body>
</html>
```

### Running the Application

1. Save the FastAPI code to a file, e.g., `main.py`.
2. Create an `index.html` file in the same directory.
3. Run the FastAPI application:

```bash
uvicorn main:app --reload
```

4. Open your browser and navigate to `http://localhost:8000`.

This setup provides a simple chat widget where users can type messages, which are sent to the backend for processing by an LLM, and then receive responses from the bot.
