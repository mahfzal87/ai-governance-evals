Here's the complete code:

```python
import os
from transformers import pipeline
import pandas as pd

# Initialize NLP model for text generation and understanding
nlp = pipeline("text-generation", model="distilgpt2")

def generate_question():
    """Generate a simple question related to junior developer skills."""
    return "Can you explain the difference between a class and an object in Python?"

def evaluate_response(response):
    """
    Evaluate the response based on predefined criteria.
    
    :param response: The candidate's response as a string
    :return: A score out of 10
    """
    # Simple scoring logic - more complex NLP could be used here
    if "class" in response and "object" in response:
        return 8
    elif "class" in response or "object" in response:
        return 5
    else:
        return 2

def main():
    print("Welcome to the Junior Developer Interview System!")
    
    # Generate a question
    question = generate_question()
    print(f"\nQuestion: {question}")
    
    # Get candidate's response
    response = input("Your answer: ")
    
    # Evaluate the response
    score = evaluate_response(response)
    print(f"Score: {score}/10")
    
    # Save to a CSV file for record-keeping
    df = pd.DataFrame({"Candidate": ["Candidate 1"], "Question": [question], "Response": [response], "Score": [score]})
    if os.path.exists("interview_records.csv"):
        existing_df = pd.read_csv("interview_records.csv")
        df = pd.concat([existing_df, df], ignore_index=True)
    df.to_csv("interview_records.csv", index=False)

if __name__ == "__main__":
    main()
```

### Explanation:
1. **NLP Model Initialization**: We use the `transformers` library to initialize a text generation model (`distilgpt2`). This can be replaced with more sophisticated models if needed.
2. **Question Generation**: A simple question is generated related to junior developer skills.
3. **Response Evaluation**: The response is evaluated based on predefined criteria (presence of key terms). More complex NLP techniques could be used for better accuracy.
4. **Scoring and Logging**: The score is printed, and the candidate's details are logged in a CSV file.
