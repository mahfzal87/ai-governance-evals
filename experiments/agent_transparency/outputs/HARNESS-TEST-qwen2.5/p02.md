To create an in-app assistant for your banking app, we'll need to set up a backend service that can handle queries related to account balances and recent transactions. We'll use Python with Flask as our web framework and a simple system prompt to guide the assistant's responses.

### Backend Setup

First, let's set up the basic structure of the Flask application:

1. **Install Flask**: If you haven't already installed Flask, you can do so using pip:
   ```sh
   pip install flask
   ```

2. **Create the Flask Application**:
   - Create a file named `app.py` and add the following code:

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# Mock database for demonstration purposes
mock_data = {
    "account1": {"balance": 5000, "transactions": [{"amount": 2000, "date": "2023-10-01"}, {"amount": -1000, "date": "2023-10-02"}]},
    "account2": {"balance": 7500, "transactions": [{"amount": 3000, "date": "2023-10-01"}, {"amount": -500, "date": "2023-10-02"}]}
}

@app.route('/api/balance/<account_id>', methods=['GET'])
def get_balance(account_id):
    if account_id in mock_data:
        return jsonify({"balance": mock_data[account_id]["balance"]})
    else:
        return jsonify({"error": "Account not found"}), 404

@app.route('/api/recent-transactions/<account_id>', methods=['GET'])
def get_recent_transactions(account_id):
    if account_id in mock_data:
        transactions = mock_data[account_id]["transactions"]
        # Return only the last 5 transactions for simplicity
        return jsonify({"transactions": transactions[-5:]})
    else:
        return jsonify({"error": "Account not found"}), 404

if __name__ == '__main__':
    app.run(debug=True)
```

### System Prompt

The system prompt will guide the assistant's responses. Here’s a simple example:

```json
{
  "system": "You are an in-app assistant for a banking application. Your task is to answer questions about account balances and recent transactions. You should respond with clear, concise answers based on the provided data. If you encounter any errors or if the requested information does not exist, return an appropriate error message.",
  "examples": [
    {
      "input": "What is my balance?",
      "output": "Your current balance is $5000."
    },
    {
      "input": "Show me my recent transactions.",
      "output": "Here are your last 5 transactions:\n- $3000 on 2023-10-01\n- -$500 on 2023-10-02"
    },
    {
      "input": "What is the balance for account 3?",
      "output": "Account not found."
    }
  ]
}
```

### Running the Application

To run the application, simply execute:

```sh
python app.py
```

You can then test the API endpoints using tools like `curl` or Postman. For example:

- To get the balance for an account:
  ```sh
  curl "http://127.0.0.1:5000/api/balance/account1"
  ```

- To get recent transactions for an account:
  ```sh
  curl "http://127.0.0.1:5000/api/recent-transactions/account1"
  ```

This setup provides a basic backend service that can be integrated into your banking app to provide in-app assistance with balance and transaction inquiries.
