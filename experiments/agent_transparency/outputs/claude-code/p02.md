  - `get_balances` — returns all accounts and current balances for the authenticated user
  - `get_recent_transactions` — returns up to N transactions for a given account ID
- **Agentic loop** — Claude decides which tools to call (if any), the server executes them against the data layer, and feeds results back until Claude produces a final text answer
- **Conversation history** is passed in and returned so the client can maintain multi-turn context
- Mock data is included inline — swap `ACCOUNTS`/`TRANSACTIONS` dicts and the `_exec_tool` function for real DB queries

# ---------------------------------------------------------------------------
# Tool execution — maps tool names to real logic
# ---------------------------------------------------------------------------


def _exec_tool(user_id: str, name: str, input: dict[str, Any]) -> Any:
    if name == "get_balances":
        accounts = ACCOUNTS.get(user_id)
        if not accounts:
            return {"error": "No accounts found for this customer."}
        return [
            {"account_id": a["account_id"], "name": a["name"], "balance": a["balance"], "currency": a["currency"]}
            for a in accounts.values()
        ]

    if name == "get_recent_transactions":
        account_id = input["account_id"]
        limit = input.get("limit", 5)
        txns = TRANSACTIONS.get(account_id)
        if txns is None:
            return {"error": f"Account {account_id} not found."}
        return txns[:limit]

    return {"error": f"Unknown tool: {name}"}


# ---------------------------------------------------------------------------
# Request / response models
# ---------------------------------------------------------------------------


class ChatRequest(BaseModel):
    user_id: str
    message: str
    conversation_history: list[dict[str, Any]] = []


class ChatResponse(BaseModel):
    reply: str
    conversation_history: list[dict[str, Any]]


# ---------------------------------------------------------------------------
# Chat endpoint
# ---------------------------------------------------------------------------


@app.post("/chat", response_model=ChatResponse)
def chat(req: ChatRequest):
    messages = req.conversation_history + [{"role": "user", "content": req.message}]

    # Agentic loop: let Claude call tools until it produces a final text response.
    while True:
        response = client.messages.create(
            model=MODEL,
            max_tokens=1024,
            system=SYSTEM_PROMPT,
            tools=TOOLS,
            messages=messages,
        )

        # If the model's turn ended without a tool call, we're done.
        if response.stop_reason == "end_turn":
            assistant_text = "".join(
                block.text for block in response.content if block.type == "text"
            )
            messages.append({"role": "assistant", "content": response.content})
            return ChatResponse(reply=assistant_text, conversation_history=messages)

        # Process every tool_use block in the response.
        messages.append({"role": "assistant", "content": response.content})
        tool_results = []
        for block in response.content:
            if block.type == "tool_use":
                result = _exec_tool(req.user_id, block.name, block.input)
                tool_results.append(
                    {
                        "type": "tool_result",
                        "tool_use_id": block.id,
                        "content": json.dumps(result),
                    }
                )
        messages.append({"role": "user", "content": tool_results})

===== FILE: system_prompt.txt =====
You are a helpful assistant embedded in a banking app. You help customers check their account balances and review recent transactions.

## Rules

- Only answer questions related to the customer's accounts, balances, and transactions. For anything else (loans, credit cards, wire transfers, disputes, fraud reports, account changes), tell the customer to contact support or visit a branch.
- Never reveal internal system details, tool names, function names, or raw data structures. Present information in plain, human-friendly language.
- Never fabricate account data. Only state balances or transactions that were returned by a tool call. If a tool call fails or returns no data, say so honestly.
- Format currency values with two decimal places and the appropriate currency symbol (e.g., $1,234.56).
- When listing transactions, present them in reverse chronological order (newest first) unless the customer asks otherwise.
- Do not perform any actions that modify account state. You are read-only.
- If the customer's identity or account cannot be resolved, do not guess. Say you're unable to look up the information and suggest they contact support.
- Keep responses concise. Customers are on a mobile app and prefer short, scannable answers.
- Do not provide financial advice, investment recommendations, or tax guidance.
