The signup page is ready at `signup.html`. Here's what I built:

**Meet Mia -- Your Onboarding Guide**

She's a friendly, encouraging assistant who sits alongside the signup form with a waving hand avatar and a speech bubble that updates as the user progresses:

| User action | Mia says |
|---|---|
| Lands on page | Introduces herself and invites them to start with their name |
| Focuses on name | Cheerful "Nice to meet you!" message |
| Moves to email | Explains why email is needed, keeps it light |
| Moves to password | Encourages them -- "You've got this!" |
| All fields filled | Celebrates and nudges them to click Create account |

**Personality traits:**
- **Warm** -- uses first-person language and casual tone ("Let's get you started")
- **Encouraging** -- positive reinforcement at every step ("You've got this!")
- **Concise** -- never overwhelming; short, friendly messages
- **Human-feeling** -- uses light emoji and conversational phrasing

**Implementation details:**
- Speech bubble animates with a gentle fade/slide transition between messages
- Avatar has a subtle waving animation
- Inputs get a green border when filled to give visual progress feedback
- Fully responsive -- Mia stacks above the form on mobile
- No external dependencies

Open `signup.html` in a browser to see Mia in action.

<script>
  const messages = {
    idle:     'Hey there! I\'m <span class="highlight">Mia</span>. I\'ll walk you through getting set up &mdash; it only takes a minute. Let\'s start with your name!',
    name:     'Nice to meet you! A name helps us personalise your experience. &#128522;',
    email:    'Great &mdash; now pop in your email so we can keep your account safe and send you the good stuff. &#9993;&#65039;',
    password: 'Last step! Pick a strong password &mdash; 8 characters or more with some letters and numbers. You\'ve got this! &#128170;',
    done:     'You\'re all set! Click <span class="highlight">Create account</span> and let\'s get you started. I\'m so glad you\'re here! &#127881;'
  };

  const bubble = document.getElementById('mia-bubble');
  const nameInput = document.getElementById('name');
  const emailInput = document.getElementById('email');
  const passwordInput = document.getElementById('password');

  function say(key) {
    if (bubble.dataset.current === key) return;
    bubble.dataset.current = key;
    bubble.style.opacity = 0;
    bubble.style.transform = 'translateY(4px)';
    setTimeout(() => {
      bubble.innerHTML = messages[key];
      bubble.style.opacity = 1;
      bubble.style.transform = 'translateY(0)';
    }, 200);
  }

  function markFilled(input) {
    if (input.value.trim()) {
      input.classList.add('filled');
    } else {
      input.classList.remove('filled');
    }
  }

  function updateMia() {
    const hasName = nameInput.value.trim().length > 0;
    const hasEmail = emailInput.value.trim().length > 0;
    const hasPassword = passwordInput.value.length > 0;

    if (hasName && hasEmail && hasPassword) {
      say('done');
    } else if (document.activeElement === passwordInput || (hasName && hasEmail)) {
      say('password');
    } else if (document.activeElement === emailInput || hasName) {
      say('email');
    } else if (document.activeElement === nameInput) {
      say('name');
    } else {
      say('idle');
    }
  }

  [nameInput, emailInput, passwordInput].forEach(input => {
    input.addEventListener('focus', updateMia);
    input.addEventListener('input', () => { markFilled(input); updateMia(); });
    input.addEventListener('blur', () => { markFilled(input); updateMia(); });
  });

  document.getElementById('signup-form').addEventListener('submit', e => {
    e.preventDefault();
    say('done');
    alert('Account created! Welcome aboard. 🎉');
  });
</script>
